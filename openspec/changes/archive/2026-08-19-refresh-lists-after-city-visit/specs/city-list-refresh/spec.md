## MODIFIED Requirements

### Requirement: Список синхронизируется после добавления города
Система SHALL обновлять результаты и статистику текущей пользовательской
list-поверхности после каждого успешного создания посещения города через общий
модальный интерфейс. Поддерживаемыми поверхностями MUST быть список всех
посещённых городов, список городов региона, список регионов, тематический
каталог коллекций, список тематической коллекции, каталог персональных
коллекций и список городов персональной коллекции владельца. Обновление MUST
использовать те же параметры фильтрации, сортировки, страны и страницы, которые
видит пользователь в момент сохранения, и MUST происходить без полной
перезагрузки страницы.

#### Scenario: Добавленный город соответствует текущей выборке
- **WHEN** пользователь успешно добавляет город, который соответствует текущим параметрам поддерживаемого списка
- **THEN** система показывает обновлённые результаты, статистику и подтверждение успешного добавления без полной перезагрузки страницы

#### Scenario: Добавленный город не соответствует текущей выборке
- **WHEN** пользователь успешно добавляет город, который исключён текущими параметрами фильтрации поддерживаемого списка
- **THEN** система сохраняет актуальную выборку результатов и обновляет зависящие от посещений статистику, пагинацию и элементы управления без полной перезагрузки страницы

#### Scenario: Пользователь добавляет повторное посещение
- **WHEN** пользователь успешно добавляет ещё одно посещение уже отмеченного города на поддерживаемой list-поверхности
- **THEN** система обновляет результаты и статистику этой поверхности без полной перезагрузки страницы

#### Scenario: Город относится к текущему региону или коллекции
- **WHEN** пользователь успешно добавляет город, представленный на текущей странице региона или коллекции
- **THEN** система отражает его актуальный статус посещения, прогресс и доступные фильтры без полной перезагрузки страницы

### Requirement: Обновляемый фрагмент списка является самостоятельным
Система SHALL предоставлять аутентифицированному пользователю обновляемый
фрагмент для каждой поддерживаемой list-поверхности. Фрагмент MUST содержать
все взаимосвязанные обновляемые элементы поверхности: результаты или пустое
состояние, статистику, пагинацию и элементы управления, чьё состояние зависит
от посещений. Фрагмент MUST поддерживать параметры соответствующего списка и
MUST рендериться без ошибок независимо от родительского шаблона.

#### Scenario: Запрос фрагмента с параметрами списка
- **WHEN** аутентифицированный пользователь запрашивает фрагмент поддерживаемого списка с его параметрами фильтрации, сортировки, страны и страницы
- **THEN** система возвращает только обновляемую область, соответствующую переданным параметрам

#### Scenario: Неаутентифицированный запрос фрагмента
- **WHEN** неаутентифицированный пользователь запрашивает фрагмент поддерживаемого списка
- **THEN** система отвечает статусом 403 без перенаправления на страницу входа

#### Scenario: Фрагмент отображает пустое состояние
- **WHEN** после создания посещения набор текущего поддерживаемого списка пуст или перестаёт быть пустым
- **THEN** фрагмент возвращает актуальное пустое состояние либо актуальные результаты вместе с зависимыми элементами поверхности

#### Scenario: Фрагмент использует фильтр склонения
- **WHEN** фрагмент содержит статистику с количеством городов, регионов или коллекций
- **THEN** система успешно рендерит корректные формы слов без ошибки отсутствующего template filter

### Requirement: Ошибка синхронизации не уничтожает отображаемые данные
Если обновляемый фрагмент недоступен, возвращает ошибку или не содержит полную
обновляемую область, система MUST сохранить состояние list-поверхности,
отображавшееся до синхронизации, и MUST сообщить пользователю, что страницу
нужно обновить вручную.

#### Scenario: Сервер не возвращает фрагмент
- **WHEN** обновление поддерживаемого списка завершается ошибкой ответа
- **THEN** система сохраняет прежнюю list-поверхность и сообщает о невозможности синхронизации

#### Scenario: Сервер возвращает неполный фрагмент
- **WHEN** ответ синхронизации не содержит полную обновляемую область
- **THEN** система не заменяет ни один из текущих элементов поверхности и сообщает о невозможности синхронизации
