# Разделять исходные данные и производные платные материалы

Исходные данные пользователя, включая посещения и загруженные фотографии, не блокируются после окончания платной подписки. Производные материалы расширенного тарифа, включая снимки итогов и созданные из них изображения, сохраняются без удаления, но становятся недоступны до возобновления подписки; так личная история остаётся у пользователя, а доступ к результатам платной обработки остаётся преимуществом тарифа.
