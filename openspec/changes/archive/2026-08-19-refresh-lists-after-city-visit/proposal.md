## Why

Общее модальное окно добавления посещённого города доступно на всех
аутентифицированных страницах. Сейчас без перезагрузки синхронизируется только
список всех посещённых городов, поэтому списки регионов и коллекций продолжают
показывать устаревшие карточки, прогресс и фильтры после успешного сохранения.

## What Changes

- Распространить синхронизацию после создания посещения на списки городов,
  регионов и коллекций, которые показывают данные текущего пользователя.
- Обновлять список после каждого успешного создания посещения, включая повторное
  посещение уже отмеченного города.
- Для каждой затронутой поверхности предоставлять серверный фрагмент с
  актуальным состоянием списка при сохранении текущих query-параметров.
- Сохранять отображаемое состояние и сообщать о необходимости ручного обновления,
  если синхронизация фрагмента завершилась ошибкой.

## Capabilities

### New Capabilities

_Нет._

### Modified Capabilities

- `city-list-refresh`: расширить обновление после сохранения посещения с
  `/city/all/list` на остальные пользовательские list-поверхности с данными о
  посещённых городах.

## Impact

- Django list views, URL-маршруты и include-шаблоны для городов, регионов и
  коллекций.
- Общий JavaScript, который обрабатывает события модального окна и заменяет
  обновляемый фрагмент страницы.
- Frontend unit-тесты обработчика и Django integration-тесты fragment endpoints.
- Публичные страницы и карты, не показывающие данные посещений текущего
  пользователя, не изменяются.
