## Purpose

Поддерживать актуальные результаты и статистику списка посещённых городов сразу
после добавления города через общий модальный интерфейс без полной перезагрузки
страницы.

## ADDED Requirements

### Requirement: Список синхронизируется после добавления города
Система SHALL обновлять результаты и статистику `/city/all/list` после успешного
добавления посещённого города через общий модальный интерфейс. Обновление MUST
использовать те же параметры фильтрации, сортировки и страницы, которые видит
пользователь в момент добавления.

#### Scenario: Добавленный город соответствует текущей выборке
- **WHEN** пользователь успешно добавляет город, который соответствует текущим параметрам списка
- **THEN** система показывает обновлённые результаты, статистику и подтверждение успешного добавления без полной перезагрузки страницы

#### Scenario: Добавленный город не соответствует текущей выборке
- **WHEN** пользователь успешно добавляет город, который исключён текущими параметрами фильтрации
- **THEN** система сохраняет текущую выборку результатов и обновляет статистику без полной перезагрузки страницы

### Requirement: Обновляемый фрагмент списка является самостоятельным
Система SHALL предоставлять аутентифицированному пользователю обновляемый
фрагмент списка, содержащий результаты и статистику без полной HTML-страницы.
Фрагмент MUST поддерживать все параметры списка и MUST рендериться без ошибок
независимо от родительского шаблона.

#### Scenario: Запрос фрагмента с параметрами списка
- **WHEN** аутентифицированный пользователь запрашивает обновляемый фрагмент с параметрами страны, фильтра, сортировки и страницы
- **THEN** система возвращает только результаты и статистику, соответствующие переданным параметрам

#### Scenario: Фрагмент использует фильтр склонения
- **WHEN** фрагмент содержит статистику с количеством городов
- **THEN** система успешно рендерит корректную форму слова без ошибки отсутствующего template filter

### Requirement: Ошибка синхронизации не уничтожает отображаемые данные
Если обновляемый фрагмент недоступен, возвращает ошибку или не содержит полный
набор заменяемых блоков, система MUST сохранить результаты и статистику,
отображавшиеся до синхронизации, и MUST сообщить пользователю, что страницу
нужно обновить вручную.

#### Scenario: Сервер не возвращает фрагмент
- **WHEN** обновление списка завершается ошибкой ответа
- **THEN** система сохраняет прежние результаты и статистику и сообщает о невозможности синхронизации

#### Scenario: Сервер возвращает неполный фрагмент
- **WHEN** ответ синхронизации не содержит результатов или статистики
- **THEN** система не заменяет ни один из текущих блоков и сообщает о невозможности синхронизации
