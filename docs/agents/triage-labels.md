# Triage Labels

Engineering skills используют пять канонических ролей. Таблица сопоставляет их с labels GitHub этого репозитория.

| Каноническая роль | Метка GitHub | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задачу должен оценить maintainer |
| `needs-info` | `needs-info` | Ожидается дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью специфицирована для агента |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполнена |

Если skill упоминает каноническую роль, использовать соответствующую ей метку GitHub.
