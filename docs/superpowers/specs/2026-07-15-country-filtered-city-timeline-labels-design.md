# Надписи хронологии с фильтром по стране

## Цель

Явно сообщать пользователю, что на странице списка городов с параметром `country` хронология содержит посещения только выбранной страны.

## Изменение

В `templates/city/list/toolbar.html` связанные с хронологией надписи зависят от `country_code` и используют `country_name|prepositional`:

- подсказка кнопки: «Показать хронологию посещений в России»;
- подпись модального окна: «Все сохранённые посещения в России»;
- пустое состояние: «В России пока нет посещённых городов в хронологии.»

Если страна не выбрана, сохраняются текущие надписи:

- «Показать хронологию посещения городов»;
- «Все сохранённые посещения»;
- «У Вас пока нет посещённых городов в хронологии.»

Заголовок модального окна и API-контракт не меняются.

## Проверка

- Integration-тест страницы подтверждает обе ветки текста: без страны и с `country=RU`.
- Существующие тесты списка городов проходят.
- Frontend production-сборка завершается без ошибок.
- Линтеры и project hooks проходят для изменённых файлов.
